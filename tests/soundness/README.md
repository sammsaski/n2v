# Soundness tests

These tests check that n2v's answers are right, not that its code runs: every reach kernel, bound pre-pass, LP certificate and specification check must enclose every true output (a failure is a false UNSAT), and every SAT must come with a witness that replays (a failure is an invalid SAT). The suite-wide rules are in [../README.md](../README.md); this file states what a soundness test here has to establish.

## What a soundness test asserts

- **Enclosure, one-sided.** The computed set contains the true value: `true >= lb - pad` and `true <= ub + pad`, never a two-sided `allclose`. The pad is zero against an exact reference (`fractions.Fraction`, mpmath), of the `1e-12` class against a float64 reference, and a derived per-cell bound against float32 onnxruntime samples. Slack in the unsound direction is never added to make a test pass.
- **Membership against the rows, not the box.** A wrong constraint row leaves the bounding box unchanged, so the check is `Star.contains(method="lp")` or an exact membership test on the predicate, on sampled true outputs including the box corners. The one-node cell plus a three-node graph (affine, operation, affine), so the relaxation's rows are consumed downstream.
- **An independent oracle.** onnxruntime on the ONNX graph, torch in float64, or exact arithmetic. Never the code's own helpers, never two n2v paths compared with each other except as an extra.
- **Inputs that can trigger the bug.** Asymmetric image shapes such as `(2, 3, 5)` with more than one channel, non-uniform bounds, asymmetric kernels, strides and pads, a star with a binding non-box row, inputs on both sides of every kink, degenerate boxes, the attribute values the VNN-COMP corpus uses.
- **Deterministic faults.** A guard for a solver or rounding failure injects the failure (a stubbed LP, a patched bound, the `inexact_scs` fixture in `conftest.py`) instead of searching for a host where it happens; it never skips because the host is well behaved.
- **Proven to bite.** Before a soundness test is accepted, the kernel is broken once (a dropped row, a flipped sign, a reversed split) and the test is watched failing. `.claude/research/34-API-Redesign/test-audit/MUTATIONS.md` records which existing tests passed that check and which did not.

## Files

`test_soundness_<layer>.py` holds the per-layer enclosure checks; `test_layer_soundness_matrix.py` runs every ONNX operation against onnxruntime; `test_*_regressions.py` and `test_leftover_*.py` guard fixed soundness bugs, one file per component, with exact-arithmetic references where rounding was the bug; `test_tighten_sound.py`, `test_refine_cpu_sound.py` and `test_input_split_sound.py` check the branch-and-bound engines against an exact oracle, with the certified GPU engine run on CPU torch everywhere through the `engine_device` fixture. The per-layer files are being folded into the reach coverage contract (one declared cell per operation, set type, method and pre-pass, with an exact rational oracle for piecewise-linear operations and an interval branch-and-bound containment proof for smooth ones); a file is deleted only once a named replacement is shown to catch the bug it guarded.
